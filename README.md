# GULSHAN TUBE

A rebranded GPL-3.0 derivative with a lightweight web experience and the original Flutter/Android client architecture.

## Website
- `index.html` — GULSHAN TUBE web interface
- `api/search.js` — Vercel serverless search endpoint
- `vercel.json` — Vercel configuration

Deploy the repository to Vercel. The web interface searches videos through the server-side endpoint and opens results in YouTube's official embedded player.

## Android
The Flutter Android application is branded **GULSHAN TUBE** and uses package id `com.gulshantube.app`.
